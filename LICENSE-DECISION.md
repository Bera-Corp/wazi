# License Decision

No public distribution license is selected in this planning baseline.

Before public release, decide between:

- Apache-2.0 for broad adoption and an explicit patent grant;
- AGPL-3.0 for stronger reciprocity around hosted modifications;
- an open-core structure with a clearly separated genuinely open-source core and commercial control-plane modules.

The decision must account for:

- desired maintainer ecosystem;
- hosted-service competition;
- contributor agreement policy;
- dependency compatibility;
- trademark policy;
- upstream application licenses;
- revenue-sharing commitments.

Until a license is added, the repository should remain private.
